Scripter

Custom scripts

Scripter is the JavaScript MIDI plug-in built into MainStage. It lets a patch do things no hardware menu offers.

  • Harp pedal settings and note filtering for glisses
  • Chord triggers and one-finger parts
  • Velocity curves for a heavy or light action
  • Sequenced and arpeggiated parts
  • Parameters that show up as screen controls
Scripter · Pad Swell.pstMIDI FX
// Pad Swell: set note velocity from the mod wheel
var PluginParameters = [{
  name: "Minimum Velocity", type: "lin",
  minValue: 1, maxValue: 127,
  numberOfSteps: 126, defaultValue: 40
}];

var mod = 0;

function HandleMIDI(event) {
  if (event instanceof ControlChange && event.number == 1) {
    mod = event.value;
  } else if (event instanceof NoteOn) {
    var floor = GetParameter("Minimum Velocity");
    event.velocity = Math.round(floor + (127 - floor) * mod / 127);
  }
  event.send();
}

Process

From score to show

I follow the same path whether I'm playing the book myself or handing it to another player.

  1. Brief

    Score, setlist, reference recordings and the gear you'll be playing on.

  2. Patch plan

    A cue-by-cue list of every sound and change, agreed before building starts.

  3. Build

    The concert is programmed, with layouts mapped to your controllers.

  4. Sitz / Band Call

    Sounds and balances adjusted in the room with the MD and the band, whether I'm playing or not.

  5. Support

    Help through the run when cuts, changes or new players come in.
